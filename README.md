# 钢结构焊缝台账、无损检测和返修闭环平台

源提示词编号：13。覆盖构件与图纸焊缝台账、二维定位、焊工资质和检测比例预警、批量检测计划、缺陷记录、返修/复检状态、Apollo GraphQL 数据层、版本快照、签字锁定和完整追溯。

## 断网现场批次合并闭环

检测员在工地断网时，焊缝缺陷与复检结论先存入「现场批次」（localStorage 持久化，跨刷新不丢），联网后在「检测返修」页统一合并到主台账：

- **合并失败保留重试**：网络/服务端失败时整批保留在现场队列，可随时重新合并（「模拟本次合并失败」按钮演示）。
- **批次幂等**：同一批次编号只处理一次，重复导入自动跳过（「重复导入批次 01」按钮演示）。
- **旧结果失效**：记录基于录入时的签字版本（`baseVersion`）；晚到结果遇到更新的签字版本即作废，不覆盖已签字版本（批次 02 演示）。
- **锁定冲突仲裁**：焊缝已进入签字锁定快照后到达的结果不写入台账，挂起到「审核锁定」页冲突列表，由质量负责人选择「采用现场结果」（从锁定版本派生新修订）或「保留快照版本」。
- 合并阶段**只**写入缺陷/复检结论与状态流转，检测比例与返修次数暂不更新。

核心合并规则为纯函数 `src/app/store/sync-engine.ts`，独立于 UI。
